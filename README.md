# Rust + React Starter

A minimal working folder with a Rust (Axum) backend and React + TypeScript (Vite) frontend.

## Requirements
- Rust and Cargo
- Node.js and npm

## Run backend
```bash
cd backend
cargo run
```
Backend: http://localhost:3000

## Run frontend
Open another terminal:
```bash
cd frontend
npm install
npm run dev
```
Frontend: http://localhost:5173

The backend includes only a basic `/health` endpoint. The frontend is the default minimal Vite React starter.
